# EV Charging Station Demand & Capacity Intelligence System

## Project Overview
An end-to-end data analytics project that analyzes EV charging sessions, identifies demand patterns, evaluates station capacity risks, and supports data-driven infrastructure planning.

## Business Problem
EV charging stations may experience peak-hour congestion, long waiting times, and uneven utilization. This project analyzes charging data to identify operational issues and recommend improvements.

## Tools & Technologies
- **Excel:** Data cleaning, validation, and preliminary analysis
- **MySQL:** Relational database design, joins, aggregations, CTEs, and window functions
- **Python:** Pandas, NumPy, Matplotlib, and exploratory data analysis
- **Power BI:** Interactive dashboards, KPIs, slicers, and capacity-risk analysis

## Dataset
The project uses four related datasets:
- `stations.csv`
- `chargers.csv`
- `customers.csv`
- `charging_sessions.csv`

The charging-session dataset contains 10,000 records.

## Project Workflow
1. Clean and validate the data using Excel and Python.
2. Store and analyze relational data using MySQL.
3. Perform exploratory data analysis and identify demand patterns.
4. Build interactive Power BI dashboards.
5. Evaluate station capacity risks and develop business recommendations.

## Power BI Dashboard Pages
1. **Executive Overview:** Sessions, revenue, energy consumption, and key performance indicators.
2. **Station Operations:** Station performance, waiting times, and congestion.
3. **Demand Analysis:** Peak hours, weekday patterns, and charging demand.
4. **Capacity & Recommendations:** Sessions per charger, capacity risks, and infrastructure planning.

## Business Questions
- Which hours have the highest charging demand?
- Which stations generate the most revenue?
- Where are waiting times highest?
- Which stations may need additional charging capacity?
- How do demand patterns vary by day and time?

## Key Deliverables
- Excel data-cleaning workbook
- MySQL database and analytical queries
- Python cleaning, EDA, and demand-analysis scripts
- Interactive Power BI dashboard
- Python-generated charts
